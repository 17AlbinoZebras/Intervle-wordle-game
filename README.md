## Intervle can be played at https://intervle.fun/

### Guess the word in 8 or fewer tries!
- Each guess must be a valid 5-letter word.
- The colors represent how far each letter is from the one in that position in the target word.
- Distances are based on the alphabet and can go in either direction.
- The alphabet loops. E.g. "Z" is 3 letters away from "C"
